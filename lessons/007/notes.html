1. 数学符号与代码形状

教材常用小写斜体表示标量、小写粗体表示向量、大写粗体表示矩阵。纯文本中用x、w、X、W标识时，应同时写出形状以减少歧义。X∈ℝⁿˣᵈ表示n行样本、每个样本d个特征。每列特征的顺序必须与权重顺序对应，继续沿用006节的列对齐要求。

对象数学含义本节PyTorch形状
X2个样本，每个3个特征(2,3)
w3个特征权重(3,)
w_column显式列矩阵(3,1)
X.T交换矩阵行列(3,2)

数学向量常按列书写，但PyTorch一维张量(3,)没有单独的行轴和列轴。需要显式列形状时用reshape(−1,1)。不要指望对一维向量做转置自动增加轴。

2. 点积是一组加权求和

两个同长度向量x与w的点积为Σⱼxⱼwⱼ，结果是标量。对本节第一行x=[1,2,3]和w=[2,−1,0.5]，先按元素相乘得到[2,−2,1.5]，求和得到1.5。

first_dot = torch.dot(X[0], w)
first_sum = (X[0] * w).sum()

torch.dot接收两个一维张量。点积结果形状为()，即004节的标量。权重可以有正有负，本例是加权和；只有额外满足非负且和为1等条件时才是加权平均。

3. 矩阵乘向量是一批点积

把每个样本放在X的一行，X@w会对每一行与同一组权重求点积。第一行得到1.5，第二行[4,5,6]得到4×2−5+6×0.5=6。加偏置0.25后预测为[1.75,6.25]。

X的n行样本 × 同一组d个权重 → n个预测
表达式结果形状含义
X*w(2,3)广播后的逐元素乘积
(X*w).sum(dim=1)(2,)沿特征轴求和
X@w(2,)矩阵与一维向量乘积
X@w_column(2,1)矩阵与列矩阵乘积

星号与@执行不同运算。只有沿正确的特征轴求和后，按元素乘积才与点积结果相同。sum()不指定轴会把所有样本也合并成一个标量，应核对计算目的。

若标签保存为(n,1)，可以让预测也保持(n,1)。把(n,)预测直接减(n,1)标签会触发005节的广播，造成(n,n)差值。需要移除已知的长度1轴时，可用squeeze(1)，明确保留样本轴。

4. 矩阵乘矩阵产生多个输出

若每个样本有k个输出，令W形状为(d,k)，每列是一套输出权重。X形状(n,d)，所以X@W形状(n,k)。其中第i行第j列为X第i行与W第j列的点积。

(n,d) @ (d,k) → (n,k)
样本轴n保留，特征轴d求和，输出轴k保留

本节W=[[2,1],[−1,0],[0.5,−1]]，两列分别为[2,−1,0.5]和[1,0,−1]。第一列与单输出权重相同；第二列给每个样本计算第一特征减第三特征，两个样本都得到−2。加偏置[0.25,1]后，两行输出为[1.75,−1]和[6.25,−1]。

multi_output = X @ W + bias
# bias形状(k,)，按005节规则加到每一行输出上

矩阵乘法要求内侧轴d匹配，不是只要求元素总数相等。也不能随意交换乘法顺序。遇到不匹配时先写轴含义，调整数据布局或权重设计，不能只为消除报错任意reshape。

5. 本节的批量计算验收

把多个样本放在同一矩阵里，一次调用完成前向计算，就能避免在Python里逐样本写同一条公式。今天用循环结果作为数值核对，未测试速度，也未训练模型。输入很小时运行耗时受启动等因素影响，不能凭这个例子声称性能提升。

per_row = torch.stack([torch.dot(row, w) for row in X])
batch_scores = X @ w
assert torch.allclose(batch_scores, per_row)

浮点运算可能因加法顺序或设备产生微小差异，因此用allclose按容差比较。形状仍要单独检查，避免允许广播的数值比较掩盖轴错误。

7. 常见误区与下一节

  • 把X*w当成每个样本的完整加权和，遗漏沿特征轴求和。
  • 把数学列向量与代码一维张量混为一谈。
  • 只检查元素数，忽略矩阵乘法的内侧轴和列语义。
  • 把张量转置后数值顺序的变化当成新训练样本，丢失行列含义。

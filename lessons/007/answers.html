第007节 · 独立参考答案

自编解答，请先完成作业。

Q1

表达式形状含义
X*w(5,3)5个样本各3个逐元素乘积
X@w(5,)5个加权和
X@w.reshape(3,1)(5,1)保留单输出轴
X@W(5,2)每个样本2个输出

点积对同位置乘积求和，所有特征被合并为一个标量。(5,3)@(5,1)的内侧轴为3和5，不相同，所以不能做矩阵乘法。

Q2 完整独立代码

第一行点积为−1+2×2=3，加0.5得到3.5。第二列权重[1,−1]给每行计算第一特征减第二特征，三行均为−1。

"""第007节代码题自编参考答案，依赖torch，CPU独立运行。"""
import torch

torch.manual_seed(42)
device = torch.device("cpu")
X = torch.tensor([[1., 2.], [3., 4.], [5., 6.]], dtype=torch.float32, device=device)
w = torch.tensor([-1., 2.], dtype=torch.float32, device=device)
per_row = torch.stack([torch.dot(row, w) + 0.5 for row in X])
batch = X @ w + 0.5
column = X @ w.reshape(-1, 1) + 0.5
W = torch.tensor([[-1., 1.], [2., -1.]], dtype=torch.float32, device=device)
bias = torch.tensor([0.5, 0.], dtype=torch.float32, device=device)
multi = X @ W + bias
assert batch.shape == (3,) and column.shape == (3, 1)
assert multi.shape == (3, 2)
assert torch.allclose(per_row, batch)
assert torch.allclose(column.squeeze(1), batch)
assert torch.allclose(batch, torch.tensor([3.5, 5.5, 7.5], device=device))
assert torch.allclose(multi, torch.tensor([[3.5, -1.], [5.5, -1.], [7.5, -1.]], device=device))
print("batch", batch.tolist(), "shape", tuple(batch.shape))
print("column", column.tolist(), "shape", tuple(column.shape))
print("multi", multi.tolist(), "shape", tuple(multi.shape))
print("PASS")

结果核对与误区

batch [3.5,5.5,7.5] shape (3,)
column [[3.5],[5.5],[7.5]] shape (3,1)
multi [[3.5,-1],[5.5,-1],[7.5,-1]] shape (3,2)
PASS

把所有乘积直接sum()会合并所有样本，丢失每个样本自己的结果。W的每列对应一套输出权重，不能把权重顺序随意交换。数值比较前先检查形状，可避免(3,)与(3,1)发生广播。

选做答案

使用one=X[:1]保留(1,2)，再算one@w.reshape(−1,1)+0.5，结果为[[3.5]]，形状(1,1)。若需要去掉输出轴，用squeeze(1)得到(1,)；不带轴的squeeze()可能连样本轴也去掉。

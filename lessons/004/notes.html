2. 张量的轴、形状与元素

张量是数值的多维排列。一个标量是0个轴，一个向量是1个轴，一个矩阵是2个轴。PyTorch用shape记录各轴长度，ndim记录轴数，numel()记录全部元素数。这里的“轴数”也称张量阶数，与线性代数中矩阵秩的概念不同。

对象shapendimnumel()
标量5()01
12个数的向量(12,)112
3行4列矩阵(3,4)212
三轴张量(2,3,4)324

对非空shape，元素总数等于各轴长度的乘积。标量没有轴，但仍存放一个数。shape=(3,4)和shape=(12,)元素数相同，组织方式不同；shape=(3,)和shape=(3,1)元素数也相同，计算配对方式却可能不同。

3. 创建方式与dtype

scalar = torch.tensor(5., dtype=torch.float32)
vector = torch.arange(12, dtype=torch.float32)
matrix = vector.reshape(3, 4)
zeros = torch.zeros((2, 3, 4), dtype=torch.float32)
ones = torch.ones((2, 2), dtype=torch.float32)
class_ids = torch.tensor([0, 1, 2], dtype=torch.int64)

tensor从给定值创建；arange(12)生成0到11，终点12不包含在内；zeros和ones按指定形状填充。dtype说明每个元素的数值类型，device说明保存和计算所在的设备。本节显式使用float32和int64，避免让隐式类型选择掩盖含义。

标签类型取决于所用损失函数。例如003节二元BCE使用浮点0/1，多类分类常见接口使用整数类别索引；不能只看“分类”二字就认定所有标签类型相同。当前class_ids仅演示整数张量，没有传入损失函数。

4. reshape要满足元素数约束

12个数能排列成(3,4)、(2,6)或(12,1)，因为轴长度乘积都等于12；不能排列成(3,5)，因为需要15个数。reshape(−1,4)让框架推断一个轴，本例得到(3,4)。通常最多指定一个−1，并确保能推断出合法形状。

12个元素 → 3行 × 4列 → 每行4个特征

如果这12个数代表3个样本，每个4个特征，行和列就有数据含义。reshape不会自动打乱、补齐或删除元素，也不会自动理解样本语义。它可能共享底层存储，也可能复制，不能仅凭调用名字认定内存关系；下一节会进一步讨论。

print(matrix.shape)    # torch.Size([3, 4])
print(matrix.ndim)     # 2
print(matrix.numel())  # 12
print(matrix.dtype)    # torch.float32

5. 两个可复现的排错步骤

第一类是reshape元素数不匹配。先数出12个元素，再检查目标3×5=15；改为3×4即可。完整文件有意触发并捕获这个错误，应该继续执行到PASS。

第二类是预测与标签形状不同。三个预测按列保存为(3,1)，三个标签却是(3,)。直接相减会隐式扩展成(3,3)，计算出不同样本的交叉配对。今天先通过检查拦住它，完整广播规则留到005节。

def checked_mse(predictions, labels):
    if predictions.shape != labels.shape:
        raise ValueError("Prediction and label shapes must match")
    return torch.mean((predictions - labels) ** 2).item()

fixed_labels = labels.reshape(-1, 1)
loss = checked_mse(predictions, fixed_labels)

本例标签[1,2,3]，预测值[2,3,4]，每个误差都是1，修复后MSE=(1²+1²+1²)/3=1。修复必须保留每个样本的对应关系，不能只为让程序运行而随意改形状。

7. 小测、常见误区与下一节

遮住上表再回答：一个(2,3,4)张量有几个轴、几个元素？一个标量是否有元素？为什么(3,)与(3,1)在本节不能混用？

  • shape是属性，numel是方法，分别写value.shape和value.numel()。
  • ndim不是元素总数，也不是矩阵秩。
  • reshape中的−1代表推断，不代表负数个元素。
  • 元素数相同不保证语义、形状或逐样本计算正确。

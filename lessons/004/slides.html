第004节 · 3/6

同样的数，形状可以不同

shapendimnumel含义
()01标量
(12,)112向量
(3,4)2123行4列
(2,3,4)324三轴张量

shape给各轴长度，ndim给轴数，numel()给总元素数。轴数与矩阵秩不同。

dtype给元素类型，device给计算设备；形状相同仍可能类型不同。

第004节 · 4/6

创建与reshape的数量约束

values = torch.arange(12, dtype=torch.float32)
matrix = values.reshape(3, 4)
zeros = torch.zeros((2, 3, 4))
ones = torch.ones((2, 2))
print(matrix.shape, matrix.ndim, matrix.numel())
12个数 → 3×4合法；3×5需要15个数 → 不合法

arange终点不包含。reshape(−1,4)可推断第一轴为3。元素数和样本语义都要核对。

reshape不承诺一定共享内存，下一节继续讨论。

第004节 · 独立参考答案

自编解答，先完成检索题和作业再核对。

课内检索与小测

  1. 输入是预测时可取得的特征，标签是训练或评估时已知、需要预测的目标。
  2. 模型把输入变为预测；损失比较预测与标签；优化器按算法更新参数。数据提供可以学习和评估的样本。
  3. 类别编号不表达数值差距，目标含义决定任务。0、1、2可以只是类别标识。
  4. 当前数据上的低误差不能保证泛化，还要检查独立数据、泄漏和使用条件。
  5. 旧预测是已经计算的张量，参数重赋值不自动重新执行旧表达式。
  6. 小表格任务应先建立简单基线，再结合独立指标、数据规模、复杂度与预算比较。

shape=(3,4)是两条轴的长度，ndim=2是轴数，numel=12是元素数。(2,3,4)有3条轴和24个元素。标量无轴但存放一个值，因此shape=()、ndim=0、numel=1。

Q1 作业概念题

a见上述角色说明。b为ndim=3、numel=2×3×4=24，标量存放一个值。c不必然是回归，应根据类别含义判断。d不充分，需要独立评估和对实际使用条件的核对。

Q2 完整独立代码

把24个顺序数按每行6个组织成4行。标签修复前为(4,)，修复后为(4,1)，预测与标签一一配对。每个预测比标签多2，MSE=(2²+2²+2²+2²)/4=4。

"""第004节代码题自编参考解答。依赖torch，CPU可独立运行。"""
import torch

torch.manual_seed(42)
device = torch.device("cpu")
values = torch.arange(24, dtype=torch.float32, device=device)
matrix = values.reshape(4, 6)
print("matrix", tuple(matrix.shape), matrix.ndim, matrix.numel(), matrix.dtype)
assert matrix.shape == (4, 6)
assert matrix.ndim == 2 and matrix.numel() == 24
assert matrix.dtype == torch.float32


def checked_mse(predictions, labels):
    if predictions.shape != labels.shape:
        raise ValueError("Prediction and label shapes must match")
    return torch.mean((predictions - labels) ** 2).item()


labels = torch.tensor([1., 2., 3., 4.], dtype=torch.float32, device=device)
predictions = (labels + 2).reshape(-1, 1)
try:
    checked_mse(predictions, labels)
except ValueError:
    print("shape mismatch rejected")
else:
    raise AssertionError("Mismatched shapes must be rejected")
fixed_labels = labels.reshape(-1, 1)
loss = checked_mse(predictions, fixed_labels)
assert predictions.shape == fixed_labels.shape == (4, 1)
assert abs(loss - 4.0) < 1e-6
print(f"fixed MSE {loss:.6f}")
print("PASS")

预期输出与误区

matrix (4, 6) 2 24 torch.float32
shape mismatch rejected
fixed MSE 4.000000
PASS

把标签重复成(4,4)虽然能凑形状，却改变了样本关系；把MSE写成误差之和会得到16，漏掉平均；把arange终点写成23只会创建23个元素。

选做答案

24不能被5整除，无法推断出合法的整数轴长度，reshape(5,−1)会报错。应先算元素总数，再决定目标形状。捕获RuntimeError只表示已观察到这个预期错误，不能把任意报错都视为成功。

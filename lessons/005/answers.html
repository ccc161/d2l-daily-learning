第005节 · 独立参考答案

自编解答，请先完成作业。

Q1

X[1]为(4,)，整数索引取第2行并移除原第0轴；X[1:2]为(1,4)，切片选择同一行但保留长度1的轴。

(3,1)+(4,)对齐成(3,1)+(1,4)，结果(3,4)。对(3,4)+(3,)，最后一轴4和3既不相等也没有1，所以不兼容。

alias与base是同一个对象；基本切片view共享base的数据；clone保存独立副本。修改共享区域会被base、alias和view观察到，clone保留复制时的数值。

Q2 完整代码

原始X每行三个特征，长度3的offsets沿行重复使用。加法产生新result，基本切片patch共享result，independent则复制修改前的块。

"""第005节代码题自编参考解答。依赖torch，CPU独立运行。"""
import torch

torch.manual_seed(42)
device = torch.device("cpu")
X = torch.arange(12, dtype=torch.float32, device=device).reshape(4, 3)
original = X.clone()
offsets = torch.tensor([10., 20., 30.], device=device)
result = X + offsets
patch = result[:2, 1:]
independent = patch.clone()
patch.add_(100)
print("result", result.tolist())
print("patch", patch.tolist())
print("independent", independent.tolist())
print("X unchanged", torch.equal(X, original))
expected = torch.tensor([[10., 121., 132.], [13., 124., 135.],
                         [16., 27., 38.], [19., 30., 41.]], device=device)
expected_copy = torch.tensor([[21., 32.], [24., 35.]], device=device)
assert torch.equal(result, expected)
assert torch.equal(independent, expected_copy)
assert torch.equal(X, original)
assert patch.shape == (2, 2)
print("PASS")

若在加100之后才clone，副本会记录修改后的值。若把independent=patch当成复制，则二者仍是同一个对象。将result生成与patch修改拆成乱序单元格也可能造成重复加100，核对时应从头重跑。

选做答案

从新建数据开始，将原地修改替换为patch=patch+100，会产生新的结果并让patch引用它，原result保持原有数值。先前存在的基本切片仍可共享原result，新的加法结果不会追随原result的后续变化。

索引、切片与按元素计算；广播规则与内存共享。

1. 索引会影响形状

X保存0到11，形状(3,4)。索引从0开始，负数从末尾计数，X[−1,−1]为最后一个元素11。基本切片start:stop含起点、不含终点，省略的边界表示沿该方向取到边缘。只给一项索引时先作用于第0轴。

表达式结果形状含义
X[1](4,)第2行，整数索引移除该轴
X[1:2](1,4)同一行，切片保留该轴
X[:2,1:3](2,2)前两行、第2与第3列
X[−1,−1]()最后一个标量

形状相似的表达式可能对后续广播产生不同影响。若下游需要批次轴，应明确决定是否保留长度1的轴。

2. 按元素运算

同形状张量的加减乘除等运算对相应位置逐个计算。X*2把每个元素翻倍；X*X把每个元素平方，结果仍为(3,4)。星号表示按元素乘法，矩阵乘法使用其他接口，后续线性代数课会展开。

X = torch.arange(12, dtype=torch.float32).reshape(3, 4)
block = X[:2, 1:3]   # [[1,2],[5,6]]
doubled = X * 2      # 第一行为[0,2,4,6]

3. 广播从末尾逐轴对齐

本课使用轴长度为正的非空张量。比较形状时从最右侧开始，缺少的前导轴视作长度1。每一对轴长度必须相同，或其中一个为1。兼容时该轴取扩展后的长度，所有轴都兼容才能运算。广播描述逻辑上的重复使用，通常不需要先物理复制输入；算术结果仍可能占用额外内存。

形状组合对齐方式结果
(3,4)+(4,)(3,4)+(1,4)(3,4)
(3,1)+(4,)(3,1)+(1,4)(3,4)
(3,4)+(3,)最后一轴4与3冲突报错

例如列向量[100,200,300]与行偏移[1,2,3,4]相加，第一行为[101,102,103,104]，最后一行为[301,302,303,304]。如果矩阵每行是一个样本，每列是一个特征，长度4的向量就能作为逐特征偏移。

004节中(3,1)预测减(3,)标签会广播成(3,3)，虽然合法，却不符合逐样本配对的意图。因此广播合法性与任务语义需要分别核对。

4. 别名、视图与独立副本

alias=base让两个名字引用同一个张量对象。基本切片view=base[:,1:]创建共享存储的视图，改变view中的数会改变base对应位置。independent=view.clone()创建独立数值副本，后续修改view不改变它。这里仅讨论基本整数索引与切片，整数组或布尔掩码等高级索引的行为应另行核对。

写法关系修改原数据后
alias=base同一对象alias看到修改
view=base[:,1:]共享存储的基本切片view对应位置改变
independent=view.clone()独立副本保留复制时的数值

reshape可能返回视图，也可能复制，不应靠它保证副本独立。需要独立副本时显式使用clone。Python对象是否相同也不能单独判断所有共享存储关系，视图就是不同对象共享数据的例子。

5. 新结果与原地修改

alias = base
view = base[:, 1:]
independent = view.clone()
view[0, 0] = 99     # base对应位置也变成99
rebound = base + 10 # 新结果，base保持当前数值
alias.add_(1)       # 原地加1，base与view都看到变化

本例base初始为[[0,1,2],[3,4,5]]。切片修改后base[0,1]=99，clone[0,0]仍为1；原地加1后base[0,1]和view[0,0]都为100。先前产生的新结果rebound在对应位置为109，不会追随之后的原地修改。

带下划线的add_表示原地版本，会修改调用对象。重复执行这种单元格可能累计修改，复现实验时应重建上游数据或重启并运行全部。本课张量不记录梯度；后续训练中原地修改还要遵守自动微分约束。

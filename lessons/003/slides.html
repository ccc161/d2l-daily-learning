第003节 · 2/6

回归与分类由目标定义

问题输出主要任务
预测价格或时长有数量意义的连续值回归
识别猫、狗或鸟类别编码分类
给无标签样本分组结构或分组无监督
通过行动争取奖励动作与累计回报强化学习

自监督从数据本身构造训练目标。序列、检索与推荐的设置要看具体输出和反馈。

同一份输入可以对应不同目标，不能仅凭输入形式选择任务。

第003节 · 3/6

同一组输入，两组标签

x = [−2,−1,0,1,2,3]
回归 y=2x+1 → [−3,−1,1,3,5,7]
分类 y=1[x≥1] → [0,0,0,1,1,1]

输入、标签、预测的形状都为(6,1)。每行一个样本，每个样本一个数。

回归用MSE衡量数值偏差。二元分类用实数logit、二元交叉熵和阈值后准确率分别描述分数与决策。

第003节 · 4/6

分数、概率与类别

logits = x - 0.5
loss = torch.nn.BCEWithLogitsLoss()(logits, labels)
predicted = (logits >= 0).float()
accuracy = (predicted == labels).float().mean()

p=sigmoid(z)。z≥0等价于p≥0.5。BCEWithLogitsLoss直接接收z，不预先sigmoid。

原始标签下，center=0.5准确率1，center=1.5准确率5/6。正确分类的有限分数仍可产生正的交叉熵。

回归MSE与分类BCE的数值不作跨任务大小比较。

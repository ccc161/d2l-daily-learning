Q1

shape=(2,)表示一条长度为2的轴，numel=2是元素数，L2范数=5表示分量按欧氏公式合成的数值长度。‖−2v‖₂=2‖v‖₂。线性性质要求加法与标量乘法得到一致处理，并不要求每个方向的长度保持不变；非均匀缩放矩阵就是例子。

[(2+h)²−4]/h=4+h，h趋近0时极限为4。h=0使差分分母为0，不能直接代入。浮点表示与相近数相减会引入数值误差，过小步长可能让输入扰动在计算中消失。

Q2 完整代码

L1=6+8=14，L2=√(36+64)=10。变换后为[−3,16]，长度√(9+256)=√265≈16.278821。对g(x)=x³，[(2+h)³−(2−h)³]/(2h)=12+h²。

"""第008节自编参考解答，依赖torch，CPU float64独立运行。"""
import torch

torch.manual_seed(42)
device = torch.device("cpu")
dtype = torch.float64
v = torch.tensor([-6., 8.], dtype=dtype, device=device)
B = torch.tensor([[0.5, 0.], [0., 2.]], dtype=dtype, device=device)
transformed = B @ v
l1 = torch.linalg.vector_norm(v, ord=1)
l2 = torch.linalg.vector_norm(v, ord=2)
after = torch.linalg.vector_norm(transformed)
assert l1.item() == 14 and l2.item() == 10
assert torch.allclose(transformed, torch.tensor([-3., 16.], dtype=dtype, device=device))
assert torch.allclose(after, torch.sqrt(torch.tensor(265., dtype=dtype, device=device)))
print("norms", l1.item(), l2.item())
print("transformed", transformed.tolist(), "L2", round(after.item(), 9))


def g(x):
    return x ** 3


x0 = torch.tensor(2., dtype=dtype, device=device)
for h in [0.1, 0.01, 0.001]:
    estimate = ((g(x0 + h) - g(x0 - h)) / (2 * h)).item()
    error = abs(estimate - 12)
    print(f"h={h:g} central={estimate:.9f} error={error:.9f}")
assert error < 2e-6
print("PASS")

不同版本末位可能有微小变化。中心差分使用左右两边点的距离2h；平方函数上的精确抵消不能推广到立方函数。范数中的负分量要平方或取绝对值，不能直接相加。

选做答案

零向量L2范数为0。可先判断范数是否大于0，非零时除以范数，零向量则保留为零并明确返回状态。具体任务也可选择报错，但不能直接除以0再把NaN当作正常结果。

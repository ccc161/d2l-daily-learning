1. 范数衡量数值大小

shape=(2,)描述两个分量，范数把这两个分量映射成一个非负标量。向量v=[3,−4]的L1范数为|3|+|−4|=7，L2范数为√(3²+(−4)²)=5，L∞范数为最大绝对值4。负分量不意味着负长度。

范数公式本例
L1Σ|vᵢ|7
L2√Σvᵢ²5
L∞max|vᵢ|4

范数满足非负性、齐次性和三角不等式。只有零向量的范数为0，且‖αv‖=|α|‖v‖。所以把v乘−2会改变方向，L2长度变成10。维数不等于长度；不同单位的特征直接放在一起计算长度，解释时还要考虑量纲与尺度。

v = torch.tensor([3., -4.], dtype=torch.float64)
l1 = torch.linalg.vector_norm(v, ord=1)
l2 = torch.linalg.vector_norm(v, ord=2)

矩阵的Frobenius范数为√ΣᵢΣⱼAᵢⱼ²，即把全部元素的平方相加再开方。本节作为补充数值核对，不把它解释为任意向量被该矩阵拉伸的固定倍数。

2. 矩阵怎样变换向量

007节已学会A@v。这里A=[[2,0],[0,0.5]]把第一个坐标乘2、第二个坐标乘0.5，使v变为[6,−2]，L2长度为√40≈6.324555。R=[[0,−1],[1,0]]把v转成[4,3]，这是平面逆时针90度旋转，L2长度仍为5。

输入变换输出L2长度
[3,−4]原向量[3,−4]5
[3,−4]A@v[6,−2]√40
[3,−4]R@v[4,3]5

A和R的形状均为(2,2)，v与输出均为(2,)。线性变换满足A(u+v)=Au+Av以及A(αv)=αAv。一般矩阵变换可能改变长度，旋转是保持L2长度的例子。007节额外加非零偏置的映射通常称为仿射变换，它把原点移动到偏置位置。

3. 从割线斜率走向导数

设f(x)=x²，在x=2附近把输入改变h。向前差分为[f(x+h)−f(x)]/h，表示两个不同点之间的割线斜率。代入可得[(2+h)²−4]/h=4+h。h趋近0时，这个变化率趋近4，因此f在2处的导数为4。差分要求h非零，导数通过极限定义，不能直接把分母设为0。

输入变化h → 函数变化f(x+h)−f(x)
两者相除 → 有限区间变化率
h趋近0且极限存在 → 局部导数

导数可描述函数对微小输入改变的敏感程度。f在2处导数4，意味着足够小的Δx下，Δf约为4Δx。本节没有更新参数，后续会把这种变化率用于理解损失优化。

4. 两种差分与步长

中心差分为[f(x+h)−f(x−h)]/(2h)，同时使用左右两边的点。对平方函数，精确算术下它恰好等于2x；这是本例的特殊结构，不能推广到所有函数。对三次函数g(x)=x³，x=2处中心差分为12+h²，仍有随h变化的近似误差。

forward = (f(x + h) - f(x)) / h
central = (f(x + h) - f(x - h)) / (2 * h)

代码会额外打印h=10⁻⁶的结果和各行实际数值。浮点数只能表示有限精度，相近的函数值相减会损失有效信息，极小h甚至可能使计算中的x+h与x相同。所以缩小步长不保证数值估计一直改善。

6. 易错点与下一节

  • 范数是标量，ndim与numel回答的是形状问题。
  • 线性变换不必保持长度，齐次性也不是说所有方向都缩放相同倍数。
  • 范数为0的向量不能直接除以自己的范数来归一化。
  • 差分值是数值近似，导数定义涉及极限；极小h不自动等于高精度。
  • 当前代码没有调用backward，差分与自动求导将在后续进一步区分。

在本地Jupyter Notebook运行、修改、重启实验；用数据、模型和损失准确描述一个预测任务。

目标：能从干净内核复现实验，能解释旧输出为何失效，能在相同数据上比较候选模型。先修为第001节的本机Python环境、基本变量和函数。

首次安装耗时单列。所有核心代码在自己的电脑CPU上运行，无需账号、云算力或下载数据。本机CUDA或Apple MPS可作选做，CPU足够完成。

1. 文档、代码和内核状态

Notebook文件保存单元格及可选输出，内核进程保存正在运行的变量。Markdown用于文字、公式和说明；代码单元格会改变内核状态。浏览器显示一段输出，并不能保证它对应眼前最新的代码。编辑参数但没有运行单元格，内核仍持有旧值；运行参数单元格后，依赖它的预测单元格也需要重跑。

执行编号反映执行顺序，出现乱序时应检查依赖。重启内核会清除运行中的变量，但文件中旧的可见输出可能仍在，重启并运行全部才会按文件顺序重新计算。保存文件和重启内核是不同操作。

3. 把预测问题说完整

假设x是一个简化传感器读数，y是待预测的校准值。本节用人为规则y=2x+1生成四个样本，便于手算。数据为x=[0,1,2,3]，y=[1,3,5,7]。模型族为ŷ=wx+b，w和b是参数，ŷ是预测，y是已知标签。数据、模型、目标函数、调整参数的算法共同构成学习任务。本节手工比较四个候选设置，参数学习算法将在后续课展开。

对象形状含义
x、y、预测(4,1)4个样本，每个1个数
w、bPython标量同一规则共享的参数

真实校准关系可能有噪声，本课人工规则只是教学数据。选择候选模型使用的也是这四个点，因此分数仅说明当前数据上的拟合，泛化需要独立数据。

4. 损失把误差变成可比较的数

MSE=(1/n)Σ(ŷᵢ−yᵢ)²，先逐个相减、平方，再取平均。对ŷ=x，误差为[-1,-2,-3,-4]，MSE=(1+4+9+16)/4=7.5。常数预测y的均值4得到MSE=5，表现优于这个斜率选错的模型；ŷ=2x+1则为0。

比较时必须使用相同标签、样本和损失定义。每个元素的平方误差都非负，MSE不会为负。多输出任务默认平均还涉及特征维度，本节每个样本只有一个输出。预测和标签形状要完全相同，避免广播导致含义变化。

5. 亲眼观察旧状态

weight, bias = 1.0, 0.0
saved_prediction = predict(x, weight, bias)
weight, bias = 2.0, 1.0
stale_loss = mse(saved_prediction, y)     # 仍为7.5
fresh_prediction = predict(x, weight, bias)
fresh_loss = mse(fresh_prediction, y)     # 重算后为0

saved_prediction是此前计算产生的张量；Python标量weight与bias重赋值不会重新执行旧表达式。这段代码特意演示旧预测，并在同一段里完成修正。它没有依赖乱序运行，也没有梯度更新。

6. 20分钟实验清单

  1. 从头运行Notebook四个代码单元格。核对shapes为(4,1)，标签为[1,3,5,7]。
  2. 观察before=7.5、stale=7.5、recomputed=0。候选损失依次为5、7.5、0、1.5，最佳为2x+1，末行PASS。
  3. 复制Notebook，用作业的3x−1规则修改数据单元格，重跑数据和所有下游代码。不要只改屏幕上的输出。
  4. 重启并运行全部，确认和修改后的输出一致，再保存。提交时附一条你对旧状态的解释。

7. 常见误区与下一节

  • 改了目标规则却只重跑结果格，y可能仍是旧标签。
  • 执行编号连续只能提示运行顺序，不能证明模型设计合理。
  • MSE为0在本课可由人工规则直接得到，不能推断模型在真实世界可靠。
  • 标签可用于拟合参数和比较损失；部署时应仅依赖可获得的输入。把待预测的标签直接当作输入会发生信息泄漏。

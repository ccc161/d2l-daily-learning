第002节 · 4/6

修改参数后为什么预测仍旧

weight, bias = 1.0, 0.0
saved_prediction = predict(x, weight, bias)
weight, bias = 2.0, 1.0
stale_loss = mse(saved_prediction, y)      # 7.5
fresh_loss = mse(predict(x, weight, bias), y)  # 0

保存的预测是已经算出的张量。参数重赋值不会自动重新执行表达式。

操作练习：先运行全部，再修改数据单元格，重跑所有依赖它的代码，最后重启并运行全部。

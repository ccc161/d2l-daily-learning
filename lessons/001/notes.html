1. 从可解释的规则开始

想预测输入数字对应的输出，训练样本来自 y=2x+1。我们知道规则用于核对，但模型只接收样本。模型 ŷ=wx+b 的 w 与 b 是可调参数。初始 w=b=0，所有预测为0。训练通过误差调整参数，逐渐接近 w=2、b=1。

输入 x → 模型 wx+b → 预测 ŷ → 与标签 y 比较 → 损失 → 梯度 → 参数更新

损失函数 L=(1/n)Σ(ŷᵢ−yᵢ)² 是平均平方误差 MSE，越小表示当前样本拟合越好。优化器按梯度决定如何更新参数。留出样本不参与更新，用于检查模型对未见输入的预测。本例规则无噪声，留出误差接近0很正常，真实数据还要考虑噪声、泄漏和分布变化。

3. 读懂输入输出与五步训练

x 与 y 的形状均为 (8,1)，即8个样本、每个1个数。nn.Linear(1,1) 接受1个特征，输出1个预测。weight 为 (1,1)，bias 为 (1,)。如果把 y 写成 (8,)，广播可能意外形成 (8,8) 的差值，应让标签与预测形状一致。

prediction = model(x)         # 前向计算
loss = loss_fn(prediction, y) # 比较预测与标签
optimizer.zero_grad()         # 清除上一轮梯度
loss.backward()               # 计算本轮梯度
optimizer.step()              # 更新参数

梯度可以理解为损失对参数微小变化的敏感程度。SGD 使用学习率控制步幅，简写为 θ←θ−η∇L。今天不要求推导；先识别 backward 负责算梯度，step 负责更新参数。no_grad 用在初始化和评估，避免记录无用计算图。

4. 运行后核对

随机种子为42，并把初始参数置0。运行120轮、学习率0.1。初始训练 MSE 理论值为8.5，最终 w 约2、b约1。留出输入 [-1.25,0.75] 的预测应约为 [-1.5,2.5]。验收为训练损失下降、留出 MSE<0.0001、参数误差均<0.01，脚本最后打印 PASS。不同版本末位小数可能变化。

学习者输入是代码内的合成数据，输出仅打印到终端。完整实现见 Python 和 Notebook。Notebook 重启内核后从头执行，若导入失败，先核对界面选中的内核。终端运行成功不能证明 Notebook 使用了同一解释器。

5. 常见问题与回顾

  • ModuleNotFoundError 通常说明包没有装进当前解释器，先用同一解释器执行 python -m pip show torch。
  • 没有 CUDA/MPS 也可完成本节。安装和运行中的设备选择应匹配。
  • 改标签后忘改断言会失败；断言表达的是当前实验的验收条件。
  • 只看训练损失容易误判泛化，留出输入必须不参与梯度更新。

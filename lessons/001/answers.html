Q1 概念题

数据提供输入x和标签y；模型以可调参数w和b把输入映射为预测；MSE量化预测与标签的偏差；优化器利用梯度更新参数。留出样本参与更新会使评估失去独立性。训练误差低还可能来自过拟合或泄漏，不能保证在真实数据上可靠。

本例规则简单且无噪声，训练点和留出点来自同一条直线。留出误差很小只支持这个合成任务上的结论。

Q2 完整代码

训练与评估都改成相同规则，模型形状、学习率、轮数无需改变。初始训练MSE理论值为17.125。预期w≈−3，b≈0.5，预测约为 [4.25,−1.75]。

"""第001节：本机 CPU 环境检查与微型回归实验。
依赖：torch。运行：python lesson.py。无需下载数据。
输入为8个训练样本、2个留出样本；输出设备、形状、损失与参数。
"""
import torch


def run_experiment():
    # 本节固定CPU作为可复现基线。CUDA/MPS仅报告可用性。
    torch.manual_seed(42)
    torch.set_num_threads(1)
    device = torch.device("cpu")
    print("PyTorch", torch.__version__)
    print("device", device)
    print("CUDA available", torch.cuda.is_available())
    print("MPS available", torch.backends.mps.is_available())

    # 每行一个样本、每个样本一个特征；标签也保留列维度。
    x = torch.tensor([-2., -1.5, -1., -.5, .5, 1., 1.5, 2.]).reshape(-1, 1)
    y = -3 * x + 0.5
    x_test = torch.tensor([[-1.25], [.75]])
    y_test = -3 * x_test + 0.5
    model = torch.nn.Linear(1, 1).to(device)
    with torch.no_grad():
        model.weight.zero_()
        model.bias.zero_()
    optimizer = torch.optim.SGD(model.parameters(), lr=0.1)
    loss_fn = torch.nn.MSELoss()
    initial_loss = loss_fn(model(x), y).item()
    print("train shapes", tuple(x.shape), tuple(y.shape))
    for _ in range(120):
        prediction = model(x)
        loss = loss_fn(prediction, y)
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
    with torch.no_grad():
        final_loss = loss_fn(model(x), y).item()
        test_prediction = model(x_test)
        test_loss = loss_fn(test_prediction, y_test).item()
    print(f"train MSE {initial_loss:.6f} -> {final_loss:.6f}")
    print(f"test MSE {test_loss:.6f}")
    print(f"weight {model.weight.item():.6f}, bias {model.bias.item():.6f}")
    print("test predictions", test_prediction.flatten().tolist())
    assert final_loss < initial_loss
    assert test_loss < 1e-4
    assert abs(model.weight.item() + 3) < .01
    assert abs(model.bias.item() - 0.5) < .01
    print("PASS")


if __name__ == "__main__":
    run_experiment()

典型误区

只改训练标签会让留出评估与任务冲突；只改断言会掩盖规则没有变更；把留出点拼回训练集会破坏独立核对。答案中的loss阈值适用于本节无噪声数据，不能直接作为所有任务的指标。

选做解释

学习率1.0对本例过大。对w的二次损失曲率为2·mean(x²)=3.75，稳定的固定步长需小于2/3.75≈0.533；1.0会让误差振荡扩大。实际任务应结合损失曲线调整步幅。

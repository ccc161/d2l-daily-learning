第001节 · 3/6

从输入到损失，再到参数更新

x → wx+b → ŷ
ŷ 与 y → MSE → 梯度 → SGD → 新的 w,b

数据给例子，模型给预测，损失给误差，优化器改变参数。

规则 y=2x+1；模型从 w=b=0 开始。MSE = Σ(ŷ−y)²/n。平方惩罚较大的误差，平均让尺度不随样本数直接增长。

训练点用于调整参数，留出点用于检查未见输入。

第001节 · 4/6

形状与五行训练代码

对象形状含义
x,y,预测(8,1)8行，每行1个数
weight / bias(1,1) / (1,)可调斜率与截距
prediction = model(x)
loss = loss_fn(prediction, y)
optimizer.zero_grad()
loss.backward()
optimizer.step()

每轮清梯度，算本轮梯度，再更新。标签不要误写为(8,)，以免广播改变计算含义。

第010/136节 · 梯度状态与条件事件

梯度累积、分离与控制流；随机试验与条件概率。

目标：区别梯度缓冲区与前向图，解释detach后的导数，读懂分支求导，并用正确分母计算条件概率。先修为009的叶子、链式法则和backward。

1. 图和梯度缓冲区是两种状态

对同一叶子x=2，第一次计算x²并反向，x.grad为4。再构建新的表达式3x并反向，新增梯度3累加到原缓冲区，得到7。x.grad.zero_()清零后，再构建x²并反向得到4。

(x ** 2).backward()  # grad=4
(3 * x).backward()   # 新图，grad累积为7
x.grad.zero_()       # 清缓冲区
(x ** 2).backward()  # 新图，grad=4

清零.grad只处理已保存梯度，不会重建或恢复旧图。每次backward需要对应的可用前向依赖；本课为每次反向写新的表达式，避免把“累积梯度”误当成“反复使用已释放的图”。本例zero_调用时.grad已经存在；初始.grad为None时不能直接对它调用zero_。

训练中可以按目标有意累积梯度，也可以在新一轮前清除旧梯度。这里先核对状态，不执行优化器更新，所以x数值保持2。

2. detach保留数值，切断相应求导路径

设a=2，square=a²=4，fixed_square=square.detach()，再计算fixed_square*a，前向值仍为8。反向时fixed_square视作当前常数4，因此对a的梯度为4。完整表达式b*b*b在b=2处的梯度则为3b²=12。

表达式前向值参与求导的路径梯度
a²的分离值乘a8乘法中直接的a4
b*b*b8完整立方依赖12

同样的前向数值可以对应不同的求导问题。detach产生的张量与原张量共享存储，不是005节的独立clone副本。本课只读分离值；若还需独立存储，可组合detach().clone()。改变共享数据可能影响反向计算，应结合依赖关系检查。

3. 控制流记录实际执行的运算

def piecewise(value):
    if value.item() > 0:
        return value ** 2
    return 3 * value

输入2时执行平方，输出4、梯度4；输入−2时执行线性分支，输出−6、梯度3。每次前向执行会形成对应的计算依赖，反向沿实际路径求导。条件判断本身不提供跨分支变化的导数。

在0处，这个分段函数左侧斜率3、右侧斜率0，数学导数不存在。程序即使按某个分支给出数值，也不能据此认定边界可导。item()在这里仅用于选择Python分支，返回的表达式仍使用原张量；不要把待求导公式全部改为Python数值运算。

4. 先定义随机试验和事件

掷一次公平六面骰，样本空间为{1,2,3,4,5,6}。事件是结果的集合。本课A为偶数{2,4,6}，B为大于3的点数{4,5,6}，交集A∩B为{4,6}。在六个结果等可能的假设下，P(A)=3/6、P(B)=3/6、P(A∩B)=2/6。

结果A偶数B大于3A且B
1否否否
2是否否
3否否否
4是是是
5否是否
6是是是

随机变量可把试验结果映射为数值，例如骰子点数；事件则描述哪些结果满足条件。表中按六种等可能结果枚举，可计算精确概率。

5. 条件概率要换分母

在已知B发生的条件下，只考虑{4,5,6}，其中4和6满足A，所以P(A|B)=2/3。一般公式为P(A|B)=P(A∩B)/P(B)，要求P(B)>0。把分母仍写为全部六个结果，会算出联合概率2/6。

全部6种结果 → 限定B：4、5、6
其中A∩B：4、6 → 条件概率2/3

本例P(A|B)=2/3与P(A)=1/2不同，所以A、B不独立。也可核对P(A∩B)=1/3不等于P(A)P(B)=1/4。独立性需要根据定义或模型假设判断，不能仅凭事件名称推断。

模拟6000次掷骰子时，用满足A且B的次数除以满足B的次数，得到经验条件频率。它通常接近理论值，但有限样本不要求正好相等。若样本中B出现0次，这个比值没有分母，代码返回None明确表示当前样本无法估计，不能当作概率0。

count_B = int(condition.sum().item())
if count_B == 0:
    return None
return int((event & condition).sum().item()) / count_B

CPU局部Generator固定种子42，避免其它随机调用改变本段样本。相同环境中可以复现；不同版本或设备不保证逐项随机序列一致，因此验收检查范围与精确枚举，不硬编码某个模拟比例。

7. 易错点与下一节

  • 混淆清除梯度缓冲区与保留/重建计算图。
  • 把detach当成数值复制，或认为它会让所有关联表达式都无法求导。
  • 把程序执行分支的梯度当成不可导边界的数学导数。
  • 用全部试验次数作为条件频率分母，误算成联合概率。
  • 把一次模拟比例当成精确理论概率。

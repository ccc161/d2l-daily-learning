第010节 · 独立参考答案

自编解答，请先完成作业。

Q1

.grad是叶子保存梯度的缓冲区，新反向结果会加到已有数值。清零缓冲区不改变已构建或已释放的前向依赖，所以还需要为反向准备可用的计算图。

detach把某个中间值作为当前常数使用。x=3时(x²).detach()*x的梯度为9，完整x³则为27，前向都为27。分支控制流只对实际执行路径求导，不能证明边界两侧导数一致。

P(A|B)=P(A∩B)/P(B)，要求P(B)>0。联合概率衡量两事件同时发生，条件概率在B内重新归一化，经验频率则是有限样本的计数比例。样本中B计数为0时不能计算这个比值。

Q2 完整代码

x²的梯度2x=6，2x贡献2，累计8；清零后固定x²=9，乘x的梯度为9。骰子事件A={1,2}、B={2,4,6}，交集只有2，因此条件概率1/3。

"""第010节自编参考解答，依赖torch，CPU独立运行。"""
import torch

torch.manual_seed(42)
x = torch.tensor(3., dtype=torch.float32, device="cpu", requires_grad=True)
(x ** 2).backward()
first = x.grad.item()
(2 * x).backward()
accumulated = x.grad.item()
x.grad.zero_()
fixed = (x * x).detach()
(fixed * x).backward()
detached_gradient = x.grad.item()
assert (first, accumulated, detached_gradient) == (6., 8., 9.)
assert x.item() == 3
print("gradients first/accumulated/detached", first, accumulated, detached_gradient)

outcomes = torch.arange(1, 7, device="cpu")
A = outcomes <= 2
B = outcomes % 2 == 0
count_B = int(B.sum().item())
count_joint = int((A & B).sum().item())
assert count_B > 0
conditional = count_joint / count_B
assert count_joint == 1 and count_B == 3
assert abs(conditional - 1/3) < 1e-12
print("counts AB/B", count_joint, count_B)
print("P(A|B)", conditional)
print("PASS")

结果核对与误区

gradients first/accumulated/detached 6.0 8.0 9.0
counts AB/B 1 3
P(A|B) 0.3333333333333333
PASS

若未清零，最后会得到旧梯度与9的和。若把分母写成6，则得到联合概率1/6。若把fixed=x*x而没有detach，求导会沿完整立方路径得到27。

选做答案

generator = torch.Generator(device="cpu").manual_seed(7)
draws = torch.randint(1, 7, (6000,), generator=generator)
A = draws <= 2
B = draws % 2 == 0
count_B = int(B.sum().item())
estimate = None if count_B == 0 else int((A & B).sum().item()) / count_B

不同种子得到不同有限样本，经验频率会变化。把种子重新设为同一个值，可在同环境中复现这批样本；不能要求每个有限样本的比例恰好1/3。

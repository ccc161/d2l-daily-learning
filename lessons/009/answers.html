Q1

偏导只改变一个坐标、保持其他坐标不变；梯度把所有偏导按输入顺序组成向量。令s=ab+a，L=s²，则∂L/∂a=2s(b+1)，∂L/∂b=2sa。a经过乘法ab和直接加a两条路径影响s，贡献分别为b和1。

requires_grad让后续相关运算在正常梯度模式下参与自动求导；backward沿依赖应用链式法则；叶子的.grad保存梯度。输入数值不会自动更新。sum把各项直接相加，mean在本题三个项下多乘1/3，所以相应梯度缩小到三分之一。

Q2 完整代码

a=1、b=2时s=3、L=9，梯度为[2×3×3,2×3×1]=[18,6]。z=[1,2,3]时逐项值为[4,10,18]，平均32/3，梯度为(2z+3)/3=[5/3,7/3,3]。

"""第009节自编参考解答，依赖torch，CPU float32独立运行。"""
import torch

torch.manual_seed(42)
device = torch.device("cpu")
x = torch.tensor([1., 2.], dtype=torch.float32, device=device, requires_grad=True)
loss = (x[0] * x[1] + x[0]) ** 2
loss.backward()
assert loss.item() == 9
assert x.grad is not None and x.grad.shape == x.shape == (2,)
assert torch.allclose(x.grad, torch.tensor([18., 6.], device=device))
assert torch.equal(x, torch.tensor([1., 2.], device=device))
print("loss", loss.item(), "gradient", x.grad.tolist())

z = torch.tensor([1., 2., 3.], dtype=torch.float32, device=device, requires_grad=True)
terms = z ** 2 + 3 * z
mean_loss = terms.mean()
mean_loss.backward()
expected = torch.tensor([5/3, 7/3, 3.], dtype=torch.float32, device=device)
assert mean_loss.shape == () and terms.shape == (3,)
assert z.grad is not None and z.grad.shape == z.shape == (3,)
assert torch.allclose(z.grad, expected)
assert abs(mean_loss.item() - 32/3) < 1e-6
assert torch.equal(z, torch.tensor([1., 2., 3.], device=device))
print(f"mean loss {mean_loss.item():.6f}")
print("mean gradient", [round(value, 6) for value in z.grad.tolist()])
print("PASS")

末位可能因浮点表示略有变化。不能把mean的梯度直接写成sum的梯度，也不能漏掉a直接进入加法的路径。重新创建本题输入即可得到新的叶子和计算图，方便独立核对。

选做答案

分别新建值相同的z_sum与z_mean，在各自前向图上做sum与mean，再比较z_sum.grad与3*z_mean.grad，应在容差内一致。这样可以避免把两个不同目标的梯度混在同一个叶子缓冲区中。

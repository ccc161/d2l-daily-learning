Q1

期望是按概率加权的平均，不必属于样本空间；六个骰子点数的平均是3.5。方差是围绕期望的平均平方偏离，标准差是方差开方，标准差与原变量单位相同。

在本节正的归约长度n下，correction=0使用分母n，correction=1使用n−1且要求有足够自由度。最小示例可以核对默认参数、dtype、归约轴、输出形状和返回数值等内容。有限样本存在随机波动，误差不必逐次单调下降，应对照理论与多次观察来解释。

Q2 完整独立代码

第一行均值4，第二行均值3；每行平方偏差之和均为4+0+4=8。除以3为8/3，除以2为4。keepdim=True后每行统计量保留为一个列值。

"""第011节自编参考答案，依赖torch>=2.0，CPU float64独立运行。"""
import torch

torch.manual_seed(42)
matrix = torch.tensor([[2., 4., 6.], [1., 3., 5.]], dtype=torch.float64, device="cpu")
print("PyTorch", torch.__version__)
print("var signature", torch.var.__doc__.strip().splitlines()[0])
row_means = torch.mean(matrix, dim=1, keepdim=True)
var0 = torch.var(matrix, dim=1, correction=0, keepdim=True)
var1 = torch.var(matrix, dim=1, correction=1, keepdim=True)
default = torch.var(matrix, dim=1, keepdim=True)
manual = ((matrix - row_means) ** 2).mean(dim=1, keepdim=True)
assert row_means.shape == var0.shape == var1.shape == (2, 1)
assert torch.allclose(row_means, torch.tensor([[4.], [3.]], dtype=torch.float64))
assert torch.allclose(var0, torch.full((2, 1), 8/3, dtype=torch.float64))
assert torch.allclose(var1, torch.full((2, 1), 4., dtype=torch.float64))
assert torch.allclose(var0, manual)
assert torch.allclose(default, var1)
print("row means", row_means.tolist())
print("var0", var0.tolist())
print("var1", var1.tolist())
print("shape", tuple(var0.shape))
print("PASS")

结果核对与误区

row means [[4.0],[3.0]]
var0 [[2.6666666666666665],[2.6666666666666665]]
var1 [[4.0],[4.0]]
shape (2,1)
PASS

实际浮点末位可能略有差异。dim=0会沿样本轴处理各列，形状和含义不同。漏掉keepdim时结果为(2,)，虽然包含同样两个数，后续广播语义却不同。

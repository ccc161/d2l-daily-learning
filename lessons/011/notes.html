第011/136节 · 期望、方差与最小API核对

期望、方差与采样估计；查找API并核对最小示例。

目标：从离散概率计算均值和方差，用有限样本估计它们，并通过文档与手算小例子确认correction、dim、keepdim。先修为010的随机试验、事件与有限样本频率。

1. 期望是按概率加权的平均

离散随机变量X的期望为μ=E[X]=Σx·P(X=x)。公平骰子的六个点数各有概率1/6，所以E[X]=(1+2+3+4+5+6)/6=3.5。期望不要求是一次试验实际可能得到的值，骰子不会掷出3.5。

当分布不均匀时，要使用各结果自己的概率；不能仍把所有可能值直接取普通平均。有限样本的平均值则把观察到的每个样本赋予相同的1/n权重，用来估计未知的总体期望。

2. 方差衡量围绕期望的平方偏离

方差σ²=Var(X)=E[(X−μ)²]=E[X²]−μ²。平方使正负偏离不会相互抵消。公平骰子E[X²]=91/6，因此方差为91/6−(3.5)²=35/12≈2.916667。标准差为√Var(X)，与原变量使用相同单位；方差使用平方单位。

量公平骰子含义
期望μ3.5概率加权中心
方差σ²35/12平均平方偏离
标准差σ√(35/12)原单位的离散程度

本节枚举的是已知模型的六个等可能结果，不是把这六个数当成从未知总体抽来的六次独立观测。这一点决定了核对时的方差分母。

3. torch.var的默认值需要读文档

对给定n个观测值，围绕样本均值的平方偏差之和除以n，得到描述这批数据的平均平方偏差。torch.var的correction=0对应这个分母；correction=1使用n−1。后者在独立同分布且方差有限等条件下，是估计总体方差的常见无偏修正。

本节使用PyTorch 2.0起提供的correction关键字，实测版本见验证记录。旧资料中的unbiased参数应按对应版本文档定位。当前已核对的PyTorch接口默认correction=1，因此torch.var(values)不会自动等于我们对公平骰子分布求出的35/12。枚举等概率分布时应显式用correction=0，与概率加权公式核对。

small = torch.tensor([1.,2.,3.], dtype=torch.float64)
torch.var(small, correction=0)  # 2/3，分母3
torch.var(small, correction=1)  # 1，分母2
torch.var(small)                # 当前接口默认correction=1

这三个数均值为2，平方偏差之和为1+0+1=2，所以差异完全可手算。选择分母取决于要描述的量与估计问题，不能只看结果是否更接近某个目标。样本数不足以支持所选自由度时，方差可能产生NaN，例如单个数配correction=1。空输入、dtype和归约长度也应在使用前核对。

4. 查API的四步方法

  1. 记录本机torch.__version__，在对应版本的官方文档定位函数。
  2. 用dir查模块可用名称，用help(torch.var)或本机文档字符串查看参数和返回值。
  3. 写下你对默认值、dtype、dim、keepdim的理解，并预测输出形状。
  4. 运行能手算的最小张量，用断言同时核对数值和形状。

本节脚本只打印本机var文档的首行，避免完整help输出淹没实验结果。Notebook中可在独立交互单元格输入torch.var?，这是交互查询语法，不应写入普通.py文件。内置函数有时不适合用inspect.signature提取签名，可以查help与官方页面。

对矩阵[[1,2,3],[4,5,6]]，dim=1沿每行的特征轴求均值或方差，得到两个结果；keepdim=True保留该轴长度1，形状从(2,)变为(2,1)，方便后续按行广播。

row_means = torch.mean(matrix, dim=1)
row_variances = torch.var(matrix, dim=1, correction=0)
kept = torch.var(matrix, dim=1, correction=0, keepdim=True)
# 均值[2,5]，方差[2/3,2/3]，kept形状(2,1)

mean输入需要浮点或复数张量。randint产生整数，所以模拟后先转为float64再求统计量。

5. 有限样本估计与误差

代码用同一个CPU Generator、种子42生成20000次公平骰子结果，再取前20、200、2000、20000个样本。对每个前缀计算样本均值与correction=0方差，并分别与3.5、35/12比较绝对误差。

在适当的独立同分布条件下，大样本有助于稳定估计，但某一条采样路径的误差不保证随每次增加样本而单调下降。不同种子的有限样本也会变化。不能挑一次接近理论的结果就认定估计永远准确。

本表中的correction=0始终描述每个样本前缀的平均平方偏差，也可作为总体方差的一种有偏估计。若研究无偏方差估计，可改用correction=1并明确记录；不要在不同样本量间悄悄混用定义。

sample = draws[:n]
mean_estimate = sample.mean()
variance_estimate = torch.var(sample, correction=0)

固定种子用于同环境复现，不保证跨版本或设备逐项序列相同。验收检查理论公式、API小例子与输出合法性，不要求随机估计恰好等于理论量，也不强制误差逐次下降。

7. 易错点与下一节

  • 把期望当成某一次必须出现的结果。
  • 把方差和标准差混用，忽略平方与单位。
  • 默认调用var却按分母n解释，遗漏correction。
  • 按错误轴求统计量，或只比较数值不比较形状。
  • 把有限样本误差的一次变化当作严格收敛规律。
